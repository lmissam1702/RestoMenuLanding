# Screenshots

Master stash of real product captures (kept out of `public/` to avoid
serving raw files; only the copies under `public/screenshots/` are used).

- `mobile 1..3.jpg` → `public/screenshots/phone/phone-1..3.jpg`
  (1080×2243, ~9:16) — used by the hero phone carousel and the Solution
  phone carousel.
- `tv 1..3.png` → `public/screenshots/tv/tv-1..3.png` (3406×1956, ~16:9) —
  all three cycle in the hero TV mockup and the Solution TV mockup.

> To swap a demo look: replace the file under `public/screenshots/...` and
> rebuild (`npm run build`). `next/image` optimization happens at request
> time, so no code changes are needed.
